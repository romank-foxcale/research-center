# Knowledge layout

- `docs/`: notes about the RC itself, written by people and agents. One durable fact, decision, hack or debt per note. Frontmatter: `id`, `title`, `status` (active, accepted, draft, superseded, archived), `summary`, `verified_at` (YYYY-MM-DD), `evidence` and `relations` (paths from the repository root that exist). At most 220 lines. Checked by `validate-knowledge.py`.
- `knowledge/`: generated by ingest. The same frontmatter, with evidence under `sources/`. Rebuilt rather than edited. Checked by `validate-research-center.py`.
- `research/<topic>/`: the brief is written in a grilling session; everything else is generated. Report citations are checked against the ledger and the judgement.
- Markdown anywhere else fails `./rc check`, except the root files and `templates/*.md`.
- A hack links to a decision or debt and states its removal condition.
